# LifeHub — трекер жизни 🧭

Десктопное приложение (Windows `.exe`) для управления жизнью в одном месте:
**финансы, задачи, привычки, цели, заметки и календарь**.

Тёмная тема, русский интерфейс, данные хранятся **локально** на вашем компьютере.

![LifeHub](build/icon.png)

---

## ✨ Возможности

- **📊 Сводка (Dashboard)** — баланс, задачи на сегодня, привычки дня, ближайшие события и график расходов на одном экране.
- **💰 Финансы** — доходы и расходы, категории, месячные бюджеты, баланс, графики (расходы по категориям и динамика по месяцам).
- **✅ Задачи** — списки дел, сроки, приоритеты, фильтры и поиск.
- **🔥 Привычки** — ежедневные отметки, серии (streak), рекорд и процент выполнения за 30 дней.
- **🎯 Цели и заметки** — долгосрочные цели с прогрессом + дневник/заметки.
- **📅 Календарь** — события по дням, отображение дедлайнов задач.
- **💾 Экспорт/импорт** — резервные копии данных в один файл.

## 🚀 Как получить `.exe` (простой способ)

> Нужен только установленный **Node.js LTS** → https://nodejs.org (скачать, установить «Далее-Далее-Готово»).

1. Скачайте этот проект (кнопка **Code → Download ZIP** на GitHub) и распакуйте,
   либо склонируйте:
   ```bash
   git clone https://github.com/ko4ka228/markul.git
   cd markul
   ```
2. Дважды кликните по файлу **`build.bat`**.
3. Дождитесь окончания сборки — откроется папка **`dist`**, где будут:
   - `LifeHub Setup 1.0.0.exe` — **установщик** (создаёт ярлык на рабочем столе и в меню «Пуск»);
   - `LifeHub-Portable-1.0.0.exe` — **портативная версия** (запускается без установки).

Готово! Запускайте приложение и пользуйтесь. 🎉

### Хочу просто попробовать без сборки `.exe`

Дважды кликните **`run.bat`** — приложение запустится в режиме разработки
(первый запуск установит зависимости автоматически).

## 🛠️ Ручная сборка (для разработчиков)

```bash
npm install        # установить зависимости
npm start          # запустить приложение
npm run dist       # собрать установщик + портативную версию (.exe)
npm run build      # собрать только установщик (NSIS)
npm run build:portable  # собрать только портативную версию
```

Собранные файлы появятся в папке `dist/`.

> Сборка `.exe` для Windows выполняется **на Windows**. На macOS/Linux
> electron-builder потребует дополнительных инструментов (wine) для Windows-таргета.

## 🗂️ Где хранятся данные

Все данные лежат в одном JSON-файле в профиле пользователя:

```
Windows: C:\Users\<Имя>\AppData\Roaming\LifeHub\lifehub-data.json
```

Открыть папку с данными можно прямо из приложения: меню **Справка → Папка с данными**.
Для переноса на другой компьютер используйте **Файл → Экспорт данных** и затем **Импорт**.

## 🧱 Структура проекта

```
markul/
├─ build.bat              # сборка .exe в один клик (Windows)
├─ run.bat               # запуск в режиме разработки
├─ package.json          # зависимости и конфигурация electron-builder
├─ build/
│  ├─ icon.ico           # иконка приложения
│  └─ icon.png
├─ scripts/
│  └─ copy-vendor.js     # копирует Chart.js в renderer/vendor перед сборкой
└─ src/
   ├─ main/
   │  ├─ main.js         # главный процесс Electron (окно, меню, IPC)
   │  ├─ preload.js      # безопасный мост в интерфейс
   │  └─ store.js        # локальное хранилище (JSON), слой данных
   └─ renderer/
      ├─ index.html
      ├─ styles.css
      ├─ app.js          # ядро UI: роутинг, помощники, модалки
      ├─ boot.js         # инициализация
      └─ modules/        # разделы приложения
         ├─ dashboard.js
         ├─ finance.js
         ├─ tasks.js
         ├─ habits.js
         ├─ goals.js
         ├─ calendar.js
         └─ settings.js
```
